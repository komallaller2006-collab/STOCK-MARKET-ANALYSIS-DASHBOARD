# 📈 Nifty 50 Stock Market Dashboard

A Streamlit dashboard for exploring and analyzing Nifty 50 stock market data using Python.

## 🚀 Features

- View Nifty 50 stock data
- Interactive charts with Plotly
- Data cleaning using Pandas and NumPy
- Date range filtering
- Volume analysis
- Moving Average (MA) visualization
- Download processed data

## 🛠 Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- Matplotlib
- yfinance

## 📂 Project Structure

```
Nifty50-Dashboard/
│── app.py
│── requirements.txt
│── requirements-dev.txt
│── README.md
│── data/
│── assets/
```

## 📦 Installation

```bash
git clone https://github.com/YOUR_USERNAME/Nifty50-Dashboard.git
cd Nifty50-Dashboard
pip install -r requirements.txt
streamlit run app.py
```
